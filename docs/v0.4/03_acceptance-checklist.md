## 実施上の前提（重要）

- **WinRemap を 1 つだけ動かした状態で行う**（インストール版が常駐していれば先に終了。二重フックは挙動不定）
- 本チェックは**コメント・空行・並び順のある設定ファイル**で行う。最低限、次の形を含めること:

```toml
# ファイル先頭のコメント

[macro]
delay_ms = 8  # ペースの同行コメント

[ime_indicator]
enabled = true

[[keymap]]
name = "emacs"  # 名前の同行コメント
application = [
  "notepad.exe",  # アプリの同行コメント
]

[keymap.remap]
"C-h" = "Back"      # 規則の同行コメント
# 独立コメント（前後を空行で挟む）

"S-C-h" = "Delete"
"C-t" = ["C-Right", "C-Left"]  # マクロ

[[keymap]]
application = ["*"]
exclude = ["game.exe"]

[keymap.remap]
CapsLock = "LCtrl"
```

- 同じフォルダーに 2 つ目の toml（例 `backup.toml`、中身は有効な設定）を置いておく（切替の確認用）
