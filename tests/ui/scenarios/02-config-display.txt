# needs: tray
Use the terminator MCP tools to test a Windows desktop app. Do exactly these steps and do not improvise extra ones.

Do not take screenshots and do not read anything from an image. Every check below is answerable from the UI Automation tree. If an element is missing, that is the result — report it as missing rather than looking at the picture to see whether it is "really" there.

1. Launch C:\Test\winremap.exe with the arguments: --config C:\Test\minimal.toml --lang en
2. Wait 5 seconds, then right-click the notification-area icon whose name contains "WinRemap" and click the menu item named "Settings". The icon sits directly on the taskbar — it has been promoted out of the overflow, so do NOT open the overflow flyout (that flyout does not open reliably under automation).
   The tray menu is a Win32 popup, and its items are NOT reliably exposed to UI Automation — sometimes they are in the tree, sometimes the popup is an unnamed container with no children at all. That is a property of Windows menus and is not what this test is about. If you cannot find the item in the tree, do NOT report the menu as broken and do NOT take a screenshot. Drive it the way Windows itself allows: with the menu open, press the S key once, then press Enter. ("Settings" and "Show log" both start with S, so the first press only highlights "Settings" — Windows invokes on a first-letter match only when the match is unique.)
3. Wait 3 seconds. The window to inspect is the one whose name contains "settings".
4. Report how the loaded config file is shown at the top of the window. It is split in two: a text element with the folder, and a combo box whose value is the file name. Report both.
5. Report the names of the navigation entries on the left ("General", "Keymaps", and the keymaps below them).
6. Click the element role:Text|name:notepad in that navigation tree, wait 3 seconds, and list the window's elements again.

The config file C:\Test\minimal.toml defines one keymap named "notepad", whose application list is notepad.exe and whose single rule remaps C-h to Back.

On the final line print exactly PASS if all of the following hold, otherwise print exactly FAIL:
  - the folder text is "C:\Test" and the combo box value is "minimal.toml"
  - the navigation tree contains "General", "Keymaps" and "notepad"
  - after step 6 the tree contains text elements named "notepad.exe", "C-h" and "Back"
Then write at most one short line per step, naming anything that was missing.
