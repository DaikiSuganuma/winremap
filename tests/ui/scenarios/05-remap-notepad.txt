Use the terminator MCP tools to test a Windows desktop app. Do exactly these steps and do not improvise extra ones. Do not touch the notification area (system tray) at all — it is not part of this test.

This binary is a test build: started with --accept-injected it also remaps input injected by other software, which is what lets your keystrokes reach its remapping. Without that flag the test cannot work, so pass it exactly as written.

1. Launch C:\Test\winremap.exe with the arguments: --config C:\Test\minimal.toml --lang en --accept-injected
2. Wait 5 seconds. Do not look for its window: it has none, it only sits in the notification area.
3. Launch notepad.exe and wait 3 seconds for its editing area to be ready.
4. Click into Notepad's editing area and type: abc
5. Read Notepad's text and report it. It must be "abc" before you continue; if it is not, print FAIL and stop.
6. Press Ctrl+H once, as a real key chord sent to Notepad. Wait 2 seconds.
7. Read Notepad's text again and report it. Also report whether a window or dialog named "Replace" opened.

The config remaps C-h to Back inside notepad.exe, so Ctrl+H must delete the last character: the text becomes "ab" and no Replace dialog opens. Notepad's own Ctrl+H opens the Replace dialog, so that dialog means the remap did not happen.

On the final line print exactly PASS if the text became "ab" and no Replace dialog opened, otherwise print exactly FAIL.
